## Featured work

**[Music Trend Recommender](https://github.com/arnav-goel10/music-trend-recommender)** — Weekly music-discovery and ranking pipeline. Normalizes candidates from six chart sources, exposes a decomposed score (momentum, cross-source confirmation, freshness, popularity dampening), and adds seeded Gumbel-Top-k exploration. Evaluated by temporal replay that ranks week `t` using only information available at `t`. Python.

**[Select to AI](https://github.com/arnav-goel10/select-to-ai)** — Chrome Manifest V3 extension that routes selected text to ChatGPT, Gemini, or Perplexity, plus a browser agent that plans and validates cross-tab tasks behind exact-origin permissions and confirmation gates. Local-first: API keys never leave the browser. Roughly 1,000 users and Chrome Web Store Featured status. JavaScript.

**[Polymarket Pricing Research](https://github.com/arnav-goel10/polymarket-pricing-research)** — Paper-only research platform for prediction-market pricing: order-book reconstruction, lead-lag and order-flow-imbalance signals, calibration, replay backtesting, and latency measurement. No live trading or order routing. Rust.
